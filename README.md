Game Description
This is a 2D Tower Defence Game developed in Unity. The objective is to protect the castle from incoming enemies by destroying them before they reach the castle.

Controls
Click/Tap on enemies to destroy them
Use the Pause button to pause the game
Resume button to continue gameplay
Implemented Features
Castle Health System
Three Enemy Types
Fast Enemy
Progressive Enemy
Heavy Enemy
Enemy Spawning System
Enemy Movement
Damage System
Health UI
Timer UI
Pause and Resume System
Victory Screen
Game Over Screen
